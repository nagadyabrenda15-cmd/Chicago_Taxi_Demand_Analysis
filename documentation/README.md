# Project Documentation

This folder contains the documentation supporting the **Chicago Taxi Demand Analysis** Power BI project.

The documentation explains how the data was prepared, how the analysis was structured, and what business insights were identified.

## 📄 Documentation

### Data Preparation

[`data-preparation.md`](./data-preparation.md)

Explains:

- Dataset size and analysis period
- Data cleaning
- Error records removed
- Data quality checks
- Business rules and calculations

### Analysis Methodology

[`methodology.md`](./methodology.md)

Explains:

- The analytical approach
- Power BI data model
- Star-schema structure
- Key measures
- Time, location, payment and company analysis

### Key Insights

[`insights.md`](./insights.md)

Summarizes:

- Major findings
- Demand patterns
- Location activity
- Payment behaviour
- Company performance
- Business recommendations

## 🎯 Purpose

The documentation is intended to make the project understandable and reproducible for someone reviewing the work without being part of the original project team.

It also demonstrates the ability to move from:

**Raw Data → Data Preparation → Data Modelling → Analysis → Business Insights → Recommendations**
